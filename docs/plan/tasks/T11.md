## Decisions

- **Scope (Ibrahim, 2026-10-08):** the generic primitives listed in Plan; the domain components go
  with the tasks that first use them (Out of scope).
- **Generator (CR-005):** `build_tokens.py` also emits each theme's `font-variation` tokens
  (`--font-variation-display`); Ibrahim edited `tokens.json`; the generated files were rebuilt
  with the script.
- **Fonts:** our own `@font-face` rules in `src/ui/fonts.css` point at the Fontsource *variable*
  packages' Latin files only (so nothing else ships), under the family names the font tokens use;
  Fraunces uses the build with the SOFT axis. The `@font-face` block disables the token rule for
  its `font-family` descriptor (it declares the name the tokens refer to).
- **Theme:** `lib/theme/applyTheme(system | light | dark)` sets `data-theme` and the `theme-color`
  meta; `system` follows `prefers-color-scheme` live until stopped. `theme-color` is read from the
  applied theme's `--bg` token, so no colour is written in code. Persisting the choice and the
  settings screen are T17 (SET-2).
- **Contrast in use:** text on the light pastels (fertile, sun, lilac) and on accent uses
  `--accent-ink`; on butter, `--ink` — the pairs `check_contrast.py` proves. The Switch thumb is
  `--border-strong` when off and `--accent-ink` on the `--accent` track when on (a proven pair:
  5.78 Sorbet, 10.69 Night Garden); found in the Night Garden snapshot review.
- **Component APIs:** variants instead of `className`/`style` (plan 5.3 rule 6; a test proves
  `Button` rejects both at compile time); icon-only controls require a label; `Chip` is the toggle
  (`aria-pressed`) and `ChipGroup` the choice (a labelled radio group, native arrow keys);
  `Sheet`/`Dialog` portal into `<body>`, share a focus trap (`internal/useFocusTrap`: focus
  inside on open, Tab/Shift+Tab cycle, Escape closes, focus returns to the opener) and
  `Dialog alert` is an `alertdialog`; `Toast` is `status`, or `alert` for errors, and does not
  auto-dismiss (5.6: nothing autoplays); `Skeleton` is static (no shimmer: nothing loops) with one
  `status` label; form controls share `internal/Field` (label, hint, error → `aria-describedby`,
  `aria-invalid`); `DateTimePicker` is the native date/time/datetime-local input styled;
  `BottomNav` uses React Router's `NavLink` (`aria-current="page"`, nested routes included).
- **Icons:** a small Life OS set drawn on the 24 px grid with a 2 px round stroke in
  `currentColor`; always decorative (`aria-hidden`).
- **Touch targets:** every interactive control has `min-height`/size from `--size-touch-target`
  (44 px).
- **Ladle:** its own minimal Vite config (Ladle bundles Vite 6; the app uses Vite 8); a provider
  imports tokens, fonts and base styles, applies Ladle's theme to `data-theme` and wraps stories in
  `<main>` on the theme's `--bg` (`.ladle/preview.css` overrides Ladle's preview background).
- **Visual tests:** Playwright runs against `ladle preview` of the production build
  (`npm run test:e2e` builds first); the story list comes from Ladle's `meta.json`, so new stories
  are covered automatically; one test per theme steps through every story with soft assertions;
  `maxDiffPixels: 0` and `threshold: 0`, animations disabled, 390 × 844 viewport, fonts awaited.
  Snapshots live in `web/tests/visual/__snapshots__/` (58 PNGs). Chromium only for now; WebKit layout checks come
  with the journeys (spec 15.1).
- **Ignored outputs:** `web/build/`, `web/test-results/`, `web/playwright-report/` in git,
  gitleaks, Prettier and ESLint.
- **Focus ring (CR-023, CR-024 approved by Ibrahim):** 2 px, 2 px offset, in the text colour of
  the surface the control sits on. Unfilled controls use `currentcolor`; filled controls (primary,
  secondary, danger buttons, FAB, chips, switch, the nav's links and add action) use
  `--surface-ink`, an alias (`var(--ink)` at the root, `var(--accent-ink)` on accent and pastel
  cards; every card resets it, so a nested card cannot inherit its parent's), because their own
  text colour is proven only on their fill. The `Card` "With controls"
  story puts filled and ghost controls on every tone; the behaviour test checks every one in both
  themes.
- **Usage note:** a primary button on an *accent* card is accent on accent (no visible edge); tasks
  use the secondary or ghost button there.
- **CR-023 tokens (applied 2026-10-08, see the CR):** Sheet and Dialog scrims are `--scrim` at
  `--opacity-scrim` (they used `--ink`, which lightened the page in Night Garden: a behaviour test
  now checks the scrim is darker than the page in both themes); every 2 px border is
  `--size-border`, disabled is `--opacity-disabled`, icons `--size-icon`/`--size-icon-sm`, the
  dialog and state text widths `--size-dialog-max`/`--size-text-max`; the bottom bar pads by
  `--size-safe-bottom` (CR-024: `env(safe-area-inset-bottom)`, applied with Ibrahim's one-time
  permission, like CR-023).
- **Layout constants (Ibrahim, 2026-10-08, CR-024):** layering and mechanics, not design values,
  stay in the CSS: Sheet `z-index: 10`, Dialog `z-index: 20`, Sheet `max-height: 90dvh` (dynamic
  viewport for iOS), the pressed button's `translateY(1px)`, and the Sheet drag rule (closes past a
  quarter of its height, at least 48 px, in `Sheet/drag.ts`).
- **Snapshot tolerance is zero:** `threshold: 0` as well as `maxDiffPixels: 0`. Playwright's default
  per-pixel colour tolerance (0.2) hid real changes (the Sorbet scrim opacity, the state badge
  colour); zero is stable here (two consecutive clean runs).
- **Box sizing:** `base.css` sets `box-sizing: border-box` everywhere, so `min-height:
  var(--size-touch-target)` is the real height (the choice chips' `<span>` was 64 px tall).
- **Non-colour state cues (5.8):** pressed and checked chips show a check mark; a busy button
  shows a still clock icon (no spinner: nothing loops) besides `aria-busy`, and stays focusable
  (`aria-disabled`, not `disabled`, so a keyboard user keeps their place: WCAG 2.4.3); its click
  is cancelled, so a busy submit button submits neither on click nor on Enter in a field; the
  current nav tab has
  the accent pill behind its icon and `aria-current`.
- **BottomNav (5.1):** `items` plus a required `action` (the "+" quick-add, a button, TOD-6) placed
  in the middle slot: Today, Health, +, Calendar, More. A `more` icon was added. The add action is
  the add-button pair `--accent-ink` on `--sun` (spec 5.3), outlined like the FAB; neither carries
  the Sticker shadow (spec 5: Sticker touches are for celebrations).
- **`color-scheme`** follows `data-theme`, so native date/time pickers and scrollbars match.
- **Sheet drag (CR-024):** the handle and header strip is the drag area (`touch-action: none`);
  the sheet follows the finger and closes past the threshold, otherwise snaps back with the motion
  tokens (0 under reduced motion). The close button, the scrim and Escape are the non-drag ways
  (WCAG 2.5.7); the handle stays `aria-hidden`. A press that starts on a control in the strip
  (the close button) is never a drag, so the browser's click reaches it.
- **Dialog `alert`** is not dismissed by a tap on the scrim, only by its buttons or Escape.
- **ErrorState/EmptyState badge** sits on `--surface` (ink and danger on surface are proven pairs).
- **Skeleton** also holds its label as visually hidden text (some screen readers ignore a status
  region's `aria-label`) and has no `aria-busy` (a busy live region holds its announcement).
- **ChipGroup** is named by its `<legend>` only (no extra `aria-label`, so it is not read twice).
- **Button line height** is the body value, so a wrapped label at large text sizes stays legible.
- **Shared styles:** form controls share `internal/Field.module.css` and the two states share
  `internal/State.module.css`; each component still has its own `Name.module.css` (plan 5.3 rule 1)
  that `composes` the shared classes, so the rules live once. Stylelint allows the CSS Modules
  `composes` property (tested in `test_stylelint.py`).
- **No `src/ui/index.ts` barrel:** features import `src/ui/<Name>` (the import-boundary lint rule
  allows exactly that), so a barrel would only be a second path in.
- **Deferred to T17 (app shell):** making the app root `inert` while a Sheet or Dialog is open
  (iOS VoiceOver's partial `aria-modal` support); the components already trap Tab and portal into
  `<body>`.
- **Toast** is a `status`/`alert` region rendered with its message; the app-wide toast host (one
  persistent live region so announcements are not missed) comes with the first task that raises
  toasts.
- **Playwright** runs with `locale: 'en-GB'` and `timezoneId: 'Europe/London'`. Snapshots are
  Chromium on Linux with the pinned Playwright version; T16's CI must run them in the matching
  Playwright container image (pixels differ across platforms; `maxDiffPixels` stays 0).
- **Keyboard tests** use Testing Library's `fireEvent` (no `user-event`: not on the dependency
  list); native controls' own keys (Enter/Space on buttons, arrows in radio groups) are the
  browser's.
