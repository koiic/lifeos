## Decisions

- **Month Grid Layout**: Sunday or Monday start per locale / profile settings (`profile.week_start`); defaults to Monday for en-GB.
- **Period Controls Context**: Placed on both Health Hub (`/health/cycle`) and Cycle Calendar (`/health/calendar`) for single-tap convenience.
- **Day Tap-through**: Tapping any day on the calendar opens `CheckInSheet` with the selected date, allowing full day editing including flow levels None/Spotting/Light/Medium/Heavy (PER-3).
