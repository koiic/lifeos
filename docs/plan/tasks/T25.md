## Decisions

- **Streak Calculation**:
  - Streak is defined as consecutive calendar days with a `daily_log` in the user's timezone.
  - If today is not yet logged, the streak is not broken: it counts consecutive days ending yesterday (preserving the active streak while today is in progress).
  - If today is logged, the streak counts consecutive days ending today.
  - If yesterday is unlogged (and today is unlogged), streak is 0.
  - If yesterday is unlogged but today is logged, streak is 1.
- **Sticker Book Design Tokens**:
  - Badge uses `--sun` background, `--ink` text, `--border-strong` border, and Sticker accent shadow `3px 3px 0 var(--border-strong)`.
  - Wiggle animation applies at milestones (3, 7, 14, 30 days) and respects `prefers-reduced-motion`.
- **Pre-selecting Mood**:
  - Tapping a mood button on the uncompleted card navigates to `/checkin?mood={value}`, pre-populating the mood in `CheckInSheet` for ultra-fast check-in (< 30s target).
