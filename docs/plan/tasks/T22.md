## Decisions

- **One sheet, max one scroll (`CHK-1`)**: Layout organized with compact pickers and clean spacing inside `Sheet`.
- **Elapsed time tracking**: Records `checkin_ms = Math.round(performance.now() - startTime)` on submit to support telemetry and verify J3 target (< 30s).
- **Settings-gated optional fields (`CHK-4`)**: Basal temperature, discharge, and intimacy only render if enabled in `settings.optional_fields`.
- **Accessible form controls**: Standard semantic elements with WAI-ARIA radio groups and toggle buttons, compliant with axe rules in Sorbet and Night Garden themes.
