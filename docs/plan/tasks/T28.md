## Decisions

- **SVG Geometry for CycleRing**: Use a standard SVG viewBox (e.g. 280x280) with centered circle and stroke-dasharray / stroke-dashoffset or arc paths (`d="M ... A ..."`) to cleanly draw the period arc and fertile window arc with round caps.
- **Accessible Aria Label**: The SVG element has `role="img"` and `aria-label` generated based on cycle day, cycle length, and phase (e.g. `Day 14 of 28, fertile window`), ensuring screen readers convey all necessary status information.
- **Informational Disclaimer**: In accordance with `CYC-3`, any presentation of fertile window or ovulation estimation prominently features the label "estimate, not contraception".
- **Single Source of Truth Copy**: All user-facing strings are defined in `web/src/copy/en-GB.ts`.
