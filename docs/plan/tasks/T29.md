## Decisions

- **Single Multi-Step Wizard Component**: Route `/setup/:step` (with valid steps 1, 2, 3, 4) mapped to `SetupWizardScreen`. Handles step transitions, URL synchronization, and step-specific forms.
- **Immediate Partial Saves**: When a user clicks "Next" or "Save & Continue" on any step, the corresponding API request (`PUT /api/v1/health/profile` or `PATCH /api/v1/me/settings`) is executed immediately so progress is preserved even if the user closes the app mid-wizard.
- **Explicit Skip Handling**: Clicking "Skip" leaves existing or default values unchanged and smoothly transitions to the next step without failing.
- **Consent Recording**: On completing or skipping the wizard, `POST /api/v1/me/consent` is triggered if consent has not yet been recorded, satisfying spec 12.6 and ONB-2.
