## Decisions

- **Single IndexedDB Database (`lifeos_offline`)**: Contains object stores `outbox`, `crypto_keys`, and `query_cache` for unified lifecycle and clean clearing upon sign-out.
- **WebCrypto AES-GCM (256-bit)**: Generated with `{ name: 'AES-GCM', length: 256 }` and stored as a non-extractable `CryptoKey` in IndexedDB.
- **Idempotency-Key header**: Every outbox mutation generates a UUID `id` used both as the primary key in `outbox` and as the `Idempotency-Key: <id>` HTTP header on flush.
- **Optimistic Updates**: Daily log mutations apply immediately to TanStack Query client cache so the UI reflects changes instantly even when offline.
