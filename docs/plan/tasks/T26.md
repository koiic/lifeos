## Scope

- Spec sections: 8.1–8.4; CYC-2, CYC-3, CYC-4, CYC-6; TV1–TV12; Hypothesis properties
- Requirements owned: CYC-2 ("Must: next period prediction as a range | Mean ± max(1, SD) days, using up to 6 included cycles; never a single day only")
- Acceptance criteria:
  - Spec 8.1: Definitions of flow day, bleed episode (gap <= 2 dry days), period start (>= 15 days or forced), cycle, period length, cycle day.
  - Spec 8.2: Inclusion rules (exclude if `user_excluded`, `outlier` [<15 or >60 days], `postpartum` [before `mode_started_on`], `data_gap` [gap > 60 days without logs]).
  - Spec 8.3: `calendar-1.0` prediction algorithm:
    - Up to 6 most recent complete and included cycles.
    - Default SD 3.0 when n < 2; sample standard deviation for n >= 2.
    - Arithmetic half-up rounding (`round_half_up`).
    - Half-width: `min(7, max(1, round_half_up(sd)))`.
    - Predicted start: `last_start + round_half_up(mean)`.
    - Range: `[predicted - half, predicted + half]` (always a range, never a single day, CYC-2).
    - Ovulation: `predicted - 14 days`; fertile: `[ovulation - 5, ovulation + 1]`. Suppressed if `ovulation <= last_start + mean_period`.
    - Confidence: "high" (n>=6 and sd<=2), "medium" (n>=3 and sd<=4), "low" otherwise.
    - Postpartum suppression: "postpartum_waiting" if postpartum mode and < 2 cycles after mode started.
  - Spec 8.4: Derived states in UI (On period, Upcoming, Window, Late, Long gap, Irregular, Waiting, No data) and cycle phases (Menstrual, Follicular, Fertile window, Luteal).
  - Spec 8.6: TV1–TV12 pass as named tests; Hypothesis property tests pass (idempotence, length span sum, `range_low <= predicted <= range_high`); 100% branch coverage of the engine module.

## Decisions

- **Pure Functional Design**: The engine is a set of pure functions and immutable dataclasses with zero dependencies on databases, async runtime, or network.
- **Arithmetic Half-Up Rounding**: Implemented via `round_half_up` to ensure exact adherence to spec 8.3 and TV1/TV5 rounding requirements (0.5 rounds up, e.g. 0.5 -> 1, 28.75 -> 29, 6.46 -> 6).
- **Hypothesis Testing**: Generates varied sequence of dates and flow levels to verify idempotency, span conservation, and range monotonicity.
