  - Concurrency & sync: LWW by `client_updated_at`. If incoming timestamp is older than existing, server retains existing and returns it with `rebuild: "not_needed"`.
  - Idempotency: `Idempotency-Key` header cached in `idempotency_keys` table for 7 days.

## Decisions

- Idempotency key responses are cached in `idempotency_keys` table encrypted under user's DEK with `aad("idempotency_keys", "response_body_enc", key, user_id)`.
- Future date check converts current UTC instant to user's profile timezone (`users.timezone`), defaulting to `Europe/London`.
- If an incoming write is superseded by an existing newer write (`incoming.client_updated_at < existing.client_updated_at`), the server preserves the existing row and returns it with status 200 and `rebuild: "not_needed"`.
