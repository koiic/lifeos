## Decisions

- **External Origin Check:** Pure bash / Node script that parses the built `web/dist/` HTML, CSS, and manifest files, ensuring all `src=`, `href=`, `@import`, and `url(...)` resources are same-origin.
- **Workflow separation:** `ci.yml` runs verification on every push and PR; `deploy.yml` handles container build/publish, staging auto-deploy, and gated production deploy.
