## Decisions

- **Greeting hours (TOD-1):** the spec names morning, afternoon, evening and night but not their
  hours: 05:00–11:59, 12:00–16:59, 17:00–21:59, 22:00–04:59, in her profile timezone. The
  `GET /today` task (its 9.3 `greeting`) must use the same. Night says "Hello" (a greeting, not a
  goodbye).
- **Tabs:** Today `/today`, Health `/health` → `/health/cycle` (current on every `/health/*`),
  Calendar `/calendar`, More `/more`. Until their tasks, Health and Calendar show what will be
  there (empty states) and More lists Settings; "+" opens the quick-add sheet with an empty
  state (its six actions are TOD-6, T40). The bar is not rendered while the sheet is open and is
  absent during setup (`/setup/notifications`); the lock screen already replaces the app.
- **Settings:** `/settings` lists Profile, Theme, Security and sessions, Notifications (the
  existing opt-in screen until T32); the other 5.2 entries join with their tasks.
- **Profile:** name (1–100 once trimmed, as the server), timezone (the browser's IANA list, hers
  always included), week start (Monday … Sunday), temperature (°C/°F); only changed fields are
  sent, profile first, then settings. A 409 loads the latest values and asks her to check them.
- **Theme:** applied the moment she picks (and remembered on this device), then saved; a failed
  save restores her saved theme. The device copy (`localStorage`, per device) only opens the next
  start in her theme before `/me` answers; `/me` stays the source.
- **Timezone (CR-030):** the client already sends `X-Timezone`; Today shows "You seem to be in
  {city}" when `/me` says they differ; "Switch to {city} time" saves it with her version, "Keep my
  timezone" hides it on this device for that zone. Right after registration her profile takes
  the device's zone (quietly; Today covers any failure).
- **Lock timeout (CR-025):** in Security, "Lock after" 1, 5 (default), 15, 30 minutes or 1 hour
  (`PUT /auth/app-lock {timeout_s}`, which keeps the PIN); another saved value is shown as its
  minutes. AppLock uses her timeout from `/me` and does not fetch `/me` while locked. The PIN
  copy no longer says "5 minutes".
- **API client:** `apiRequest` takes extra headers (for `If-Match`); `ApiError.body` keeps the
  problem body.
- **Screens without new components:** everything is built from existing `src/ui` components, so
  no new stories or snapshots.
- **Test timing:** the router test that first loads the lazy shell and Today chunks waits up to
  12 s under the full parallel run (it takes under a second alone).
