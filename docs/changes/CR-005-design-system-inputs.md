# CR-005 — Design-system inputs: tokens.css location and incomplete typography tokens

- Raised by: Claude Code, first-session cross-check (affects T11)
- Date: 2026-10-06
- Status: proposed

## Problem

1. **Where `tokens.css` lives.** Spec 11.1 layout: `lib/theme/  tokens.css, theme switcher,
   theme-color meta`. Plan 5.1 and the kit: `web/src/ui/tokens.css` and `web/src/ui/tokens.ts`
   (generated by `scripts/build_tokens.py`, protected by the guard). Plan 4 says "where a rule and the
   spec disagree, the spec wins and the rule gets a change request".
2. **Typography values in spec 5.4 / 5.8 that are not in `design/tokens.json`.** Plan 5.1 says
   tokens.json is "the only place a design value is defined ... typography (5.4)", but it lacks:
   - body weight "400–500" and label/chip weight "700" (`font-weight` has only `display` and `heading`);
   - Fraunces "SOFT 100" (needs `font-variation-settings: "SOFT" 100` for Night Garden headings);
   - the focus-ring offset "2 px offset" (5.8) — `size.focus-ring` covers the width only.
   Without tokens, T11 components would have to hard-code these values.

## Options

1. **Keep `web/src/ui/` for the generated token files; `lib/theme/` holds only the theme switcher and
   theme-color logic. Add to tokens.json:** `font-weight.body: 400`, `font-weight.body-strong: 500`,
   `font-weight.label: 700` (shared); `font-variation.display`: `"SOFT" 100` (dark) / `normal`
   (light); `size.focus-offset: 2px`. — impact: spec 11.1 text; tokens.json (Ibrahim edits);
   regenerate CSS/TS.
2. **Move generated files to `web/src/lib/theme/`** to match spec 11.1, plus the same token additions.
   — impact: build_tokens.py, guard.py, post_edit.py, plan 5.1 all change.

## Recommendation

Option 1: the token files are the design-system component library's foundation and the kit already
generates and guards them in `src/ui/`; only the spec's layout line needs to follow.

## Impact if approved

- Spec sections to change: 11.1 (`lib/theme/` description; `ui/` includes generated tokens).
- Plan: none (5.1 already says `web/src/ui/`).
- Tokens changes: add the weights, font variation and focus offset above; run
  `python3 scripts/build_tokens.py`.
- Tasks affected: T11 (blocked).
